# 领域约定

院内制剂传承证据链围绕方证、制剂工艺与质量证据保存可核对的业务记录。外部主体使用不含真实身份信息的稳定引用编号，时间采用带偏移量的 ISO 8601 字符串，材料只保存受控引用和 `sha256` 摘要。

## 四条版本线

同一方药的不同侧面分开管理，各自线性演进：

- **流派传承**：`PrescriptionSource` 记录流派与匿名化传承来源，关联追加式方证证据。
- **临床验证**：`Evidence` 为匿名方证证据，只保存授权摘要、`sha256` 指纹与机构内部受控引用；含患者信息的原始材料不离开所属机构。
- **制剂组方 / 生产工艺 / 质控规格**：每个制剂拥有三条 `VersionLine`。新版本必须以线内上一版为基线，任一时刻至多一个草稿；晋级必须集齐临床、药学、生产三个部门的独立签署，签署与晋级在同一临界区内校验落库，并发签署不会越过缺失环节。质控版本必须给出标准生效日 `effective_from`。

## 批次与流通

批次在产出时锁定当刻生效的三个版本（按生效日选择），之后版本晋级或停用不回溯改写已生产批次。批次可拆分为子批次（数量守恒、继承版本），分发到适用机构时生成授权记录。紧急停用针对版本或批次，只阻断后续动作，不改写历史。跨院撤回覆盖目标批次及其全部子批次的所有领取机构，逐机构确认，可查询覆盖缺口。

## 事件与审计

交换事件包含 `event_id`、`subject_ref`、`occurred_at`、`source_sequence` 和 `payload_digest`。来源序号只在同一来源内递增，接收方必须保留原始发生时间，不得用到达时间覆盖。示例内容仅用于说明字段形状，不代表真实人员、机构或业务结论。

审计人员凭批号调用 `GET /audit/batches/{batchNo}`，可看到批次依据的方证、工艺与质控版本（含完整基线链与签署记录）、各次授权、当前可流通范围，以及撤回通知是否覆盖所有领取机构。
